VAS00 Backups

A private backup utility operated by rcvillasenor for the VAS-00 game server.

The utility is being configured to copy encrypted Conan Exiles and Project Zomboid backup archives to the operator's Google Drive using rclone. It is for personal use, not a public service.

Google Drive Access

The utility requests the drive.file permission to create, list, download, verify and manage its own backup files and folders. It does not request general access to unrelated Drive files.

Backups are intended to be encrypted on the server before upload. This public website contains information about the utility; it does not provide access to backups or the game server.

Privacy Policy

Questions: project issue tracker. Do not post credentials, backup contents or other private information.
