VAS00 Backups Privacy Policy

VAS00 Backups is a personal backup utility operated by rcvillasenor. This policy describes its intended operation as it is configured.

Data and Purpose

The utility processes game save archives, configuration files and associated server data solely to back up and recover the operator's game server. Archives may contain player identifiers, game account data and server configuration secrets.

Using Google Drive's drive.file permission, the utility accesses files it creates or files explicitly authorized for it. It processes their contents and metadata to upload, download, verify and manage backup history. It may also read available Drive storage information to avoid filling the account.

Storage and Security

The intended configuration encrypts backup contents and filenames locally with rclone before uploading them to the operator's Google Drive. Google receives encrypted files and service metadata such as file sizes and upload times. Local source archives remain on the operator's computers.

Google authorization tokens and encryption credentials are stored privately on the operator's computers. They are not included in this website or its public repository. Encryption recovery information must be kept separately by the operator.

Sharing and Retention

The utility does not sell backup data, use it for advertising or send it to AI services. Google Drive stores the uploaded files as the selected storage provider. Only the operator and people explicitly granted access by the operator should have access to backups and recovery credentials.

Backup history is retained according to the operator's configured policy; older unprotected archives may be deleted. The operator can delete cloud copies in Google Drive, remove local copies, or revoke the application's authorization through Google Account settings. Revoking authorization does not itself delete existing backups.

This Website and Contact

This informational site is hosted by GitHub Pages. It has no login form, analytics scripts or application tracking cookies. GitHub may process visitor information according to its privacy statement.

Questions or corrections: project issue tracker. Never post private data or credentials there.
